# Escala Web

Web de una sola página (index.html) en tres idiomas (ES/EN/IT), publicada con GitHub Pages desde `main`.

## Skills de diseño

Para cualquier trabajo de diseño o front-end, usa las skills instaladas en `.claude/skills/` y léelas antes de empezar:

- **impeccable** (Impeccable, https://impeccable.style/docs/): diseño, auditoría, crítica y pulido de la interfaz.
- **emil-design-eng** y el resto de skills de Emil Kowalski (https://emilkowal.ski/skill): animaciones, detalles de UI y criterio de diseño (`animate`, `review-animations`, `improve-animations`, `animation-performance`, etc.).

Para actualizarlas: `npx impeccable update` y `npx skills update -p`.
